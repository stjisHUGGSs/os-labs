# ЛР №10 — командные файлы (Windows и Linux)

| Файл | Что это |
|---|---|
| `lab10_base.bat`, `lab10_base.sh` | Базовый вариант: запросить имя каталога, создать его и **скопировать** в него все файлы `*.c` |
| `lab10_ext.bat`, `lab10_ext.sh` | Усложнённый вариант: файлы `*.c` **переносятся** в подкаталоги с именем файла без расширения (`proga.c` → `<каталог>/proga/proga.c`) |
| `demo/` | Файлы для пробного запуска (`hello.c`, `prog1.c`, `prog2.c`, `notes.txt`) |

Расширение файлов задано переменной `EXT` в начале каждого скрипта. В задании оно
«своё для каждого студента» (например, `.c` или `.txt`); здесь выбрано `c`.

Скрипты обрабатывают файлы **текущего каталога**, поэтому запускать их нужно из папки с
файлами. Усложнённые скрипты перемещают файлы, поэтому для проверки лучше сделать копию
`demo`.

## Windows

```
cd demo
..\lab10_base.bat
..\lab10_ext.bat
```

Комментарии и сообщения в `.bat` — на английском: `cmd` читает такие файлы в кодовой
странице OEM, и русский текст ломает разбор (проверено).

## Linux

```
cd demo
bash ../lab10_base.sh
bash ../lab10_ext.sh
```

Результаты — в `reports/lab10.md`.
