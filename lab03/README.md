# ЛР №3 — блокировка файлов в Windows

| Файл | Что это |
|---|---|
| `lab3.c` | Базовый вариант: открытие файла с запретом совместного доступа, ожидание освобождения |
| `lab3_run.bat` | Усложнённый вариант: автозапуск трёх экземпляров через ~3 с |
| `text.txt` | Подготовленный текстовый файл, который читает программа |

Команды выполняются из папки `lab03`.

## Базовый вариант

```
gcc lab3.c -o lab3.exe -Wall
.\lab3.exe
```

Запустить два (или три) экземпляра в разных окнах командной строки или из
Проводника. Первый открывает `text.txt` с режимом разделения `0` и держит его 8 с;
остальные получают `ERROR_SHARING_VIOLATION` (код 32), пишут об этом и ждут
освобождения, затем читают файл. Если `text.txt` нет — сообщение и выход.
Сообщения цветные и выводятся по центру окна консоли.

## Усложнённый вариант

```
.\lab3_run.bat
```

Запускает три экземпляра `lab3.exe`, каждый в своём окне (`start` + `cmd /k`), с
паузой около 3 с между запусками (пауза сделана через `ping 127.0.0.1 -n 4`).
Комментарии в `.bat` — на английском: `cmd` читает файл в кодовой странице OEM, и
русский текст ломает разбор.

Результаты и ответы на контрольные вопросы — в `reports/lab03.md`.
