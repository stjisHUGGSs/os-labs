# ЛР №5 — события мыши в консоли Windows

| Файл | Что это |
|---|---|
| `lab5.c` | Базовый вариант: щелчок на букве — в последней строке символ и его координаты |
| `lab5_ext.c` | Усложнённый вариант: щелчок на букве — символ меняет регистр на месте и перекрашивается |
| `text.txt` | Текстовый файл, содержимое которого выводится в консоль |

Команды выполняются из папки `lab05`. Запускать нужно в окне консоли (вывод не
переадресовывать).

```
gcc lab5.c -o lab5.exe -Wall
.\lab5.exe

gcc lab5_ext.c -o lab5_ext.exe -Wall
.\lab5_ext.exe
```

Левая кнопка мыши — щелчок по символу, правая — выход. На пробелах и пустых
местах экрана программа ничего не делает.

Результаты и ответы на контрольные вопросы — в `reports/lab05.md`.
