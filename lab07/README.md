# ЛР №7 — многопоточные программы в Linux

| Файл | Что это |
|---|---|
| `lab7.c` | Базовый вариант: три нити, отмена нитей, мьютекс на вывод |
| `lab7_ext.c` | Усложнённый вариант: нити 1 и 3 используют одну общую процедуру |

Команды выполняются из папки `lab07`. Окно терминала — не меньше 32 строк.

```
gcc lab7.c -o lab7.out -Wall -pthread
./lab7.out

gcc lab7_ext.c -o lab7_ext.out -Wall -pthread
./lab7_ext.out
```

Каждая нить выводит в свой столбец буквы (по строке на шаг, буква повторяется
`2 × номер нити` раз). Главная нить на 6-м шаге пытается отменить нить 1, на 11-м —
нить 3. Нити 1 и 3 запрещают отмену; нить 3 на 13-м шаге разрешает её (отложенный
режим), а между 16-м и 17-м шагами стоит точка отмены (`pthread_testcancel`).

Результаты и ответы на контрольные вопросы — в `reports/lab07.md`.
