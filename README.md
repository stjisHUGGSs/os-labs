## Сборка

* Windows — MinGW: `gcc labNN/файл.c -o labNN/файл.exe -Wall`
* Linux — gcc: `gcc labNN/файл.c -o labNN/файл.out -Wall` (для нитей — ещё `-pthread`)

Готовые бинарные файлы в репозиторий не входят (`*.exe`, `*.out` в `.gitignore`).
Windows-программы запускаются в командной строке (`cmd`), Linux-программы проверялись в
Ubuntu 24.04 (WSL 2).
