# ЛР №4 — блокировка файлов в Linux

| Файл | Что это |
|---|---|
| `lab4.c` | Базовый вариант: блокировка по записи через `fcntl` (`F_SETLK`, затем `F_SETLKW`) |
| `lab4_run.sh` | Усложнённый вариант: автозапуск трёх экземпляров через 3 с |
| `text.txt` | Подготовленный текстовый файл |

Команды выполняются из папки `lab04`.

## Базовый вариант

```
gcc lab4.c -o lab4.out -Wall
./lab4.out
```

Запускать в двух консолях (виртуальные консоли `Alt-F1`…`Alt-F6` или два окна
терминала). Первый экземпляр сразу ставит блокировку по записи на весь файл,
читает файл, выводит его, «засыпает» на 7 с и снимает блокировку. Второй видит,
что файл заблокирован (и каким процессом), и ждёт через `F_SETLKW`. Сообщения
цветные (ANSI) и выводятся по центру экрана.

## Усложнённый вариант

```
./lab4_run.sh
```

Скрипт запускает три экземпляра с паузой 3 с, каждый в своём окне `tmux`
(переключение: `Ctrl-b n` / `Ctrl-b p`, выйти: `Ctrl-b d`). Если `tmux` нет,
экземпляры запускаются в фоне, а вывод попадает в `lab4_N.log`.

Результаты и ответы на контрольные вопросы — в `reports/lab04.md`.
