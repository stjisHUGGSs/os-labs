# ЛР №8 — читатели и писатели на семафорах (Linux)

| Файл | Что это |
|---|---|
| `lab8.c` | Базовый вариант: 3 писателя, 3 читателя, 12-символьный буфер, два двоичных семафора |
| `lab8_ext.c` | Усложнённый вариант: максимальные задержки задаются параметрами запуска (в долях 0,1 с) |

Команды выполняются из папки `lab08`. Терминал — не меньше 100×30.

```
gcc lab8.c -o lab8.out -Wall -pthread
./lab8.out

gcc lab8_ext.c -o lab8_ext.out -Wall -pthread
./lab8_ext.out 9 2          # писатель: до 0,9 с между половинами, читатель: до 200 мс
./lab8_ext.out              # без параметров: 10 и 3 (1 с и 300 мс)
```

Для сравнения можно собрать программу без синхронизации (операции P и V
отключаются), читатели тогда видят «смесь» названий:

```
gcc lab8.c -o lab8_nosync.out -Wall -pthread -DNO_SYNC
```

Результаты и ответы на контрольные вопросы — в `reports/lab08.md`.
